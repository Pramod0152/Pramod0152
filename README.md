# 💫 About Me

Hi, I'm **Pramod** 👋 a backend developer from Kathmandu, Nepal.

I work remotely with a team in South Korea, building the APIs and real-time systems behind apps: chat, video calls, payments and notifications. My daily tools are **NestJS, TypeScript and PostgreSQL**.

What I enjoy most is making slow things fast. Recently I brought a query down from about 12 seconds to 2 by fixing N+1 problems and adding indexes.

Outside work I build side projects, like a multi-channel notification service, a chat app and a RAG-based knowledge platform. Right now I'm learning unit testing with Jest.
